🐔 El Pollo Loco

A browser-based 2D jump-and-run game built with HTML, CSS, and object-oriented JavaScript. The player explores a colorful game world, collects coins and salsa bottles, defeats enemies, and faces the final boss in an exciting battle.

🚀 Live Demo

Live Version:
https://franziskakalloch.developerakademie.net/el%20pollo%20loco/

✨ Features

* Smooth 2D side-scrolling gameplay
* Object-oriented JavaScript architecture
* Animated player and enemies
* Collectible coins and salsa bottles
* Throw mechanics
* End boss battle
* Health, coin, and bottle status bars
* Keyboard controls
* Responsive game screen

🛠️ Technologies

* HTML5
* CSS3
* JavaScript (ES6)
* Object-Oriented Programming (OOP)
